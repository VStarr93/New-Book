# New Book

A short, heartfelt animal fantasy for a dad (33) and his son (11), planned and written together. The feeling moves from irritated, to sad, to happy.

## Read it on a phone

After GitHub Pages is enabled, open:

**https://vstarr93.github.io/New-Book/**

That link loads `book.html` and the pictures together in the browser. You do not need a laptop.

Phone tip: downloading the GitHub zip and opening `book.html` from Files often shows missing pictures. Phone browsers block local HTML from loading nearby image files for security. A website link (GitHub Pages) fixes that.

### One-time Pages setup

1. Merge the GitHub Pages pull request (or push these files to `main`).
2. On GitHub: **Settings → Pages**.
3. Under **Build and deployment → Source**, choose **GitHub Actions**.
4. Wait for the “Deploy GitHub Pages” workflow to finish (Actions tab), then use the link above.

## How this project grows

Work in this order. Stay on a step until it feels solid, then move on. Earlier notes can change later.

1. **Start here** — agree on who the book is for, what kind of story it is, and how you will work together. See [planning/00-start-here.md](planning/00-start-here.md).
2. **Collect ideas** — write down sparks without picking a winner yet. See [planning/01-ideas.md](planning/01-ideas.md).
3. **Choose one idea** — pick the idea you both want to follow, or combine two.
4. **Turn it into a story** — answer the questions that give the idea a person, a problem, and a shape. See [planning/02-from-idea-to-story.md](planning/02-from-idea-to-story.md).
5. **Outline, then draft** — add chapter files only after the story shape is clear.

## What you need before you start writing chapters

You do not need a finished plot, a cast of characters, or an ending on day one. You need seven things:

| What | Why it matters |
| --- | --- |
| Who the book is for | A story for a younger reader is built differently from a story just for the two of you. |
| The feeling | Funny, scary, adventurous, mysterious, or heartfelt — this guides every later choice. |
| The kind of story | Fantasy, real life, science fiction, mystery, animals, and so on. |
| A few sparks | Short "what if" ideas. Messy is fine. One sentence each is enough. |
| How long it should be | A short story, a chapter book, or a longer novel. This keeps the plan the right size. |
| How you will work | Who suggests ideas, who writes them down, when you meet, and how you decide. |
| What to leave out | Topics, scariness, or situations you do not want in this book. |

Those answers live in [planning/00-start-here.md](planning/00-start-here.md). Fill that in together before you try to build the full story.
